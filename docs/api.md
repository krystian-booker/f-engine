# Engine API reference

Generated by `fengine --write-api` from the C++ bindings. These are the
services the engine provides; game logic lives in Lua (see `lualib/fe` and docs/scripting.md).

## `fe.log`

Logging to the console and log output.

| Name | Type | Description |
| --- | --- | --- |
| `info` | `fun(message: string)` | Log information. |
| `warn` | `fun(message: string)` | Log a warning. |
| `error` | `fun(message: string)` | Report a script error (shown in the developer overlay). |

## `fe.dev`

Development helpers: tracebacks, watches, profiling and errors.

| Name | Type | Description |
| --- | --- | --- |
| `traceback` | `fun(thread?: thread, message?: string): string` | Traceback of a coroutine (or the caller). |
| `enabled` | `fun(): boolean` | True in development builds (editor, hot reload, watchdog). |
| `zone` | `fun(name: string, milliseconds: number)` | Record a timing shown in the profiler. |
| `clock` | `fun(): number` | High-resolution seconds for profiling. |
| `errors` | `fun(): {message: string, time: number}[]` | Recent script errors. |
| `clear_errors` | `fun()` | Clear the recorded script errors. |
| `console` | `fun(code: string): string` | Evaluate Lua and return printable results. |

## `fe.time`

Game time.

| Name | Type | Description |
| --- | --- | --- |
| `ticks` | `fun(): integer` | Fixed ticks since start. |
| `now` | `fun(): number` | Game seconds since start. |
| `wall` | `fun(): number` | Wall-clock seconds since the Unix epoch (save timestamps). |

## class `RandomStream`

Deterministic PCG32 random stream. Same seed, same sequence on every platform.

| Name | Type | Description |
| --- | --- | --- |
| `:float` | `fun(): number` | Uniform in [0, 1). |
| `:int` | `fun(low: integer, high: integer): integer` | Uniform integer in [low, high]. |
| `:chance` | `fun(probability: number): boolean` | True with the given probability. |
| `:range` | `fun(low: number, high: number): number` | Uniform real in [low, high). |
| `:pick` | `fun(list: any[]): any` | Random element of a sequence. |
| `:shuffle` | `fun(list: any[]): any[]` | Shuffle a sequence in place. |
| `:state` | `fun(): string` | Opaque state string (for debugging). |

## `fe.random`

Seeded random streams. Replays and tests fix the base seed.

| Name | Type | Description |
| --- | --- | --- |
| `new` | `fun(seed?: integer): RandomStream` | New stream; without a seed it derives one from the run seed. |
| `seed` | `fun(): integer` | The run's base seed. |

## `fe.json`

JSON conversion.

| Name | Type | Description |
| --- | --- | --- |
| `decode` | `fun(text: string): any` | Parse JSON text. |
| `encode` | `fun(value: any, pretty?: boolean): string` | Serialize a value (tables, strings, numbers, booleans). |
| `read` | `fun(path: string): any` | Read and parse a JSON file inside the game folder ('@fe/' for lualib). |

## `fe.fs`

Read-only access to files inside the game folder.

| Name | Type | Description |
| --- | --- | --- |
| `read` | `fun(path: string): string` | Read a text file. |
| `exists` | `fun(path: string): boolean` | Whether a file or folder exists. |
| `list` | `fun(folder: string): string[]` | Sorted entries of a folder; folders end with '/'. |

## `fe.app`

Application, window and asset-loading services.

| Name | Type | Description |
| --- | --- | --- |
| `title` | `fun(): string` | Game title from game.json. |
| `set_title` | `fun(title: string)` | Change the window title. |
| `virtual_size` | `fun(): integer, integer` | Virtual canvas resolution. |
| `viewport` | `fun(): integer, integer` | Window size in pixels. |
| `pixels_per_unit` | `fun(): integer` | Sprite pixels per world unit. |
| `quit` | `fun()` | Close the game. |
| `fullscreen` | `fun(enabled: boolean)` | Switch fullscreen. |
| `capture` | `fun(path: string)` | Write a PNG screenshot into the user data folder. |
| `preload` | `fun(paths: string[]): integer` | Decode assets on a worker thread; returns a ticket. |
| `progress` | `fun(ticket: integer): number` | Preload progress 0..1. |
| `image_size` | `fun(path: string): integer, integer` | Pixel size of an image (0, 0 when missing). |
| `sprite_clips` | `fun(path: string): table<string, {loop: boolean, length: number, directions: integer}>` | Clip information of a sprite animation. |

## `fe.save`

Per-user persistence. Saves are JSON documents the game defines; the engine adds no schema.

| Name | Type | Description |
| --- | --- | --- |
| `write` | `fun(slot: string, data: table, meta?: table)` | Atomically write a save slot. |
| `read` | `fun(slot: string): table?, table?` | Read a slot's data and metadata (nil when empty). |
| `list` | `fun(): {slot: string, meta: table, modified: number, thumbnail: boolean}[]` | All saved slots. |
| `delete` | `fun(slot: string)` | Delete a slot. |
| `thumbnail` | `fun(slot: string)` | Capture the next frame as the slot's thumbnail. |
| `read_config` | `fun(): table` | Read the player's settings file. |
| `write_config` | `fun(settings: table)` | Write the player's settings file. |

## `fe.input`

Action-mapped input. Raw inputs are named 'key:Z', 'pad:a', 'pad:leftx+', 'mouse:left'. The engine has no default bindings; scripts define every action.

| Name | Type | Description |
| --- | --- | --- |
| `define` | `fun(action: string, inputs: string[], threshold?: number)` | Define or replace an action. |
| `define_axis` | `fun(name: string, spec: {negative?: string[], positive?: string[], analog?: string[], deadzone?: number})` | Define an axis from digital and analog inputs. |
| `clear` | `fun()` | Remove all actions and axes. |
| `bind` | `fun(action: string, inputs: string[])` | Rebind an action. |
| `bindings` | `fun(action: string): string[]` | Current inputs of an action. |
| `pressed` | `fun(action: string): boolean` | Went down this tick. |
| `held` | `fun(action: string): boolean` | Currently down. |
| `released` | `fun(action: string): boolean` | Went up this tick. |
| `repeating` | `fun(action: string, delay?: number, interval?: number): boolean` | Pressed, then repeats while held (menu navigation). |
| `held_time` | `fun(action: string): number` | Seconds the action has been held. |
| `axis` | `fun(axis: string): number` | Axis value -1..1. |
| `raw` | `fun(input: string): number` | Raw input value. |
| `pressed_inputs` | `fun(): string[]` | Raw inputs that went down this tick (for rebinding screens). |
| `last_device` | `fun(): string` | 'keyboard', 'gamepad' or 'mouse' — pick button prompts with this. |
| `device_name` | `fun(): string` | Gamepad model name. |
| `mouse` | `fun(): number, number` | Mouse position in canvas pixels. |
| `mouse_moved` | `fun(): boolean` | Mouse moved this tick. |
| `wheel` | `fun(): number` | Wheel movement this tick. |
| `feed` | `fun(input: string, value: number)` | Inject a raw input (tests and replays). |

## `fe.text`

Fonts, colors, icons and markup. Markup tags: {color:x} {icon:id} {wait:s} {speed:cps}; other {tags} are passed to the resolver set with fe.text.resolver.

| Name | Type | Description |
| --- | --- | --- |
| `font` | `fun(name: string, spec: {files: string[], size?: number, pixel?: boolean})` | Define a font: .fnt bitmap fonts and/or .ttf/.otf faces, first match wins per character. |
| `color` | `fun(name: string, color: any)` | Name a color for {color:name}. |
| `icon` | `fun(id: string, spec: {image: string, rect?: number[]})` | Register an {icon:id} image. |
| `resolver` | `fun(resolver: fun(tag: string): string?)` | Resolve custom tags such as {player} or {var:gold}. |
| `units` | `fun(markup: string): {count: integer, wait: table<integer, number>, speed: table<integer, number>}` | Reveal units for typewriter effects. |
| `measure` | `fun(markup: string, options?: table): number, number, integer` | Width, height and line count. |
| `paginate` | `fun(markup: string, options: table, lines: integer): string[]` | Split text into pages that fit `lines` wrapped lines of `options.width`. |
| `plain` | `fun(markup: string): string` | Markup with tags removed. |

## `fe.canvas`

2D drawing in virtual pixels (origin top-left). All game UI is built from these calls each frame.

| Name | Type | Description |
| --- | --- | --- |
| `size` | `fun(): integer, integer` | Canvas size in virtual pixels. |
| `rect` | `fun(x: number, y: number, w: number, h: number, color?: any)` | Filled rectangle. |
| `line` | `fun(x0: number, y0: number, x1: number, y1: number, color?: any, thickness?: number)` | Line segment. |
| `image` | `fun(path: string, x: number, y: number, options?: {w?: number, h?: number, src?: number[], color?: any, flip_x?: boolean, flip_y?: boolean, linear?: boolean})` | Draw an image or part of one. |
| `nine_slice` | `fun(path: string, x: number, y: number, w: number, h: number, border: number/number[], options?: table)` | Stretchable window frame. |
| `text` | `fun(markup: string, x: number, y: number, options?: {font?: string, size?: number, color?: any, width?: number, align?: string, visible?: integer, shadow?: any, outline?: any, line_gap?: number}): number, number` | Draw text; returns its size. |
| `push_clip` | `fun(x: number, y: number, w: number, h: number)` | Clip drawing to a rectangle (nested clips intersect). |
| `pop_clip` | `fun()` | Restore the previous clip. |
| `push` | `fun(transform: {x?: number, y?: number, scale?: number, sx?: number, sy?: number, ox?: number, oy?: number, rotation?: number, alpha?: number})` | Push a 2D transform and opacity (UI animation). |
| `pop` | `fun()` | Pop the last transform. |
| `layer` | `fun(layer: integer)` | Draw subsequent calls on a layer; higher layers draw on top. |
| `additive` | `fun(enabled: boolean)` | Additive blending for subsequent calls (glows). |
| `quad_count` | `fun(): integer` | Quads recorded this frame (tests and profiling). |

## `fe.audio`

Music layers with loop points and crossfades, sounds and buses.

| Name | Type | Description |
| --- | --- | --- |
| `music` | `fun(path: string, options?: {layer?: string, fade?: number, loop_start?: number, loop_end?: number, volume?: number, loop?: boolean, sync?: boolean})` | Play music on a layer, crossfading from what was there. |
| `stop_music` | `fun(layer?: string, fade?: number)` | Fade out one layer, or all music. |
| `music_volume` | `fun(layer: string, volume: number, fade?: number)` | Mix a music layer (stems). |
| `current_music` | `fun(layer?: string): string` | Path playing on a layer. |
| `sound` | `fun(path: string, options?: {volume?: number, pitch?: number, pan?: number, loop?: boolean, bus?: string}): integer` | Play a sound; returns a voice id. |
| `stop` | `fun(voice: integer, fade?: number)` | Stop a voice. |
| `set_voice` | `fun(voice: integer, volume: number, pan: number)` | Change a playing voice. |
| `bus_volume` | `fun(bus: string, volume?: number): number` | Get or set a bus volume ('master', 'music', 'sfx', ...). |
| `available` | `fun(): boolean` | An audio device is open. |

## `fe.screen`

Full-screen effects. Scripts animate these values (see fe.tween); renderers apply them.

| Name | Type | Description |
| --- | --- | --- |
| `set` | `fun(settings: {fade?: number[], flash?: number[], tint?: number[], letterbox?: number, transition?: {kind?: string, progress?: number, centre?: table, color?: any}})` | Change screen effects. Colors are {r,g,b,amount}. |
| `get` | `fun(): table` | Current screen effect values. |

## class `Entity`

A world entity. Components are optional; a script decides what an entity is.

| Name | Type | Description |
| --- | --- | --- |
| `:valid` | `fun(): boolean` | False once destroyed. |
| `.key` | `integer` | Stable number for table keys (unique within its world). |
| `.id` | `string` | Unique name within the world ('' = anonymous). |
| `:world` | `fun(): World` | Owning world. |
| `.position` | `{x: number, y: number, z: number}` | World position (feet). |
| `.layer` | `integer` | Grid layer. |
| `.facing` | `{x: number, z: number}` | Facing direction on the ground plane. |
| `:cell` | `fun(): {x: integer, z: integer, layer: integer}` | Grid cell under the entity. |
| `:place` | `fun(position: table, layer?: integer, keep_height?: boolean)` | Teleport; height snaps to the grid unless keep_height. |
| `:face` | `fun(target: Entity/string/{x: number, z: number})` | Face an entity, a compass direction ('north'...) or a vector. |
| `:set_yaw` | `fun(radians: number)` | Rotation for mesh entities. |
| `:configure` | `fun(spec: table)` | Add or change components (same fields as world:spawn). |
| `:move_to` | `fun(target: table, options?: {path?: boolean, speed?: number})` | Walk to a position (pathfinding by default). Emits 'arrived' or 'blocked'. |
| `:stop` | `fun()` | Stop moving. |
| `:drive` | `fun(x: number, z: number)` | Steer this tick with a velocity in units/second (player control). |
| `:jump` | `fun(target: table, options?: {height?: number, duration?: number, layer?: integer})` | Arc to a position. Emits 'landed'. |
| `:moving` | `fun(): boolean` | Walking, jumping or being driven. |
| `:can_occupy` | `fun(position: table, layer?: integer): boolean` | Whether the entity would fit there. |
| `:mover` | `fun(settings?: {speed?: number, max_step?: number, radius?: number, collide?: boolean})` | Add or configure movement. |
| `:sprite` | `fun(settings?: table): table` | Add or change the sprite; returns its current state. |
| `:clip` | `fun(clip: string, restart?: boolean)` | Play a sprite clip. |
| `:mesh` | `fun(settings?: table)` | Add or change a glTF mesh (props, doors...). |
| `:play` | `fun(animation: string, loop?: boolean)` | Play a mesh animation by name. |
| `:light` | `fun(settings: table/nil)` | Attach a light (position is an offset); nil removes it. |
| `:emitter` | `fun(settings: table/boolean/nil)` | Attach particles; a boolean pauses/resumes; nil removes. |
| `:collider` | `fun(settings: {radius?: number, height?: number, solid?: boolean}/nil)` | Contact shape. Solid colliders block movers; all report contacts. |
| `:audio` | `fun(settings: {sound: string, radius?: number, volume?: number}/nil)` | Looping positional sound (waterfalls, fires). |
| `:tags` | `fun(): string[]` | Tags. |
| `:tag` | `fun(tag: string)` | Add a tag. |
| `:untag` | `fun(tag: string)` | Remove a tag. |
| `:has_tag` | `fun(tag: string): boolean` | Whether the entity has a tag. |
| `:props` | `fun(): table` | Authored properties (a copy). |
| `:data` | `fun(): table` | Script-side table that lives as long as the entity. |
| `:attach` | `fun(parent: Entity, offset?: table)` | Follow another entity (emote balloons, held items). |
| `:detach` | `fun()` | Stop following. |
| `:screen_position` | `fun(lift?: number): number, number, boolean` | Canvas position of the entity (plus `lift` units up); third value false when behind the camera. |
| `:destroy` | `fun()` | Remove the entity. |

## class `Camera`

Orbit camera. Scripts implement follow, zones, rotation and cutscene paths by setting these each tick.

| Name | Type | Description |
| --- | --- | --- |
| `.target` | `table` | Point the camera looks at. |
| `.yaw` | `number` | Degrees around the vertical axis. |
| `.pitch` | `number` | Degrees above the horizon (90 = top-down). |
| `.distance` | `number` | Distance from the target. |
| `.fov` | `number` | Vertical field of view in degrees. |
| `.shake` | `table` | Visual offset (screen shake), not interpolated. |
| `:snap` | `fun()` | Skip interpolation after a cut. |
| `:position` | `fun(): table` | Eye position. |
| `:project` | `fun(point: table): number, number, boolean` | Canvas position of a world point. |
| `:ray` | `fun(x: number, y: number): table, table` | World ray through a canvas position. |

## class `World`

A loaded map: grid, entities, camera, lights and environment.

| Name | Type | Description |
| --- | --- | --- |
| `.name` | `string` | World name. |
| `.map_id` | `string` | Map folder id. |
| `.map_name` | `string` | Display name. |
| `:props` | `fun(): table` | Map properties (music, encounters, anything a game stores). |
| `:points` | `fun(): table<string, {position: table, facing: table, layer: integer}>` | Named points (spawns). |
| `:placements` | `fun(): {id: string, type: string, position: table, facing: table, layer: integer, props: table}[]` | Authored placements; scripts decide what to spawn for each type. |
| `:zones` | `fun(): {id: string, type: string, min: table, max: table, layer: integer, props: table}[]` | Authored zones (camera regions, encounter areas, triggers). |
| `:zones_at` | `fun(position: table, layer?: integer): {id: string, type: string, props: table}[]` | Zones containing a position. |
| `:environment` | `fun(): table` | Lighting, fog, sky, weather and post-processing settings. |
| `:set_environment` | `fun(changes: table)` | Change environment values (day/night, weather, post effects). Only this world changes; the map file does not. |
| `:time` | `fun(): number` | Simulated seconds. |
| `:spawn` | `fun(spec: {id?: string, position: table, layer?: integer, facing?: table, yaw?: number, scale?: number/table, tags?: string[], sprite?: table, mesh?: table, light?: table, emitter?: table, collider?: table, mover?: table, audio?: table, props?: table, keep_height?: boolean}): Entity` | Create an entity with the given components. |
| `:find` | `fun(id: string): Entity?` | Entity by id. |
| `:query` | `fun(filter?: {tag?: string, near?: table, radius?: number}): Entity[]` | Entities with a tag and/or within a radius. |
| `:events` | `fun(): {type: string, a?: Entity, b?: Entity, name?: string}[]` | Events since the last call: contact_begin/end, arrived, blocked, landed, anim_event, anim_finished, zone_enter/exit. |
| `:draw` | `fun()` | Render this world this frame (call from draw; several worlds draw in call order). |
| `:camera` | `fun(): Camera` | The world's camera. |
| `:grid_size` | `fun(): integer, integer, integer` | Grid width, depth and layer count. |
| `:cell` | `fun(x: integer, z: integer, layer?: integer): {height: number, walkable: boolean, ramp: string, tags: string[], props?: table}?` | Grid cell data, nil outside the map. |
| `:set_cell` | `fun(x: integer, z: integer, layer: integer, changes: {height?: number, walkable?: boolean, ramp?: string, tags?: string[], add_tags?: string[], remove_tags?: string[], props?: table})` | Change a cell at runtime (burning grass, frozen water, collapsing bridges). |
| `:cells_with_tag` | `fun(tag: string): {x: integer, z: integer, layer: integer}[]` | All cells carrying a tag. |
| `:height_at` | `fun(x: number, z: number, layer?: integer): number` | Ground height at a position. |
| `:path` | `fun(from: table, to: table, rules?: table): table[]` | A* path of cells (excluding the start). Rules: diagonal, max_step, max_up, max_down, blocked_tags, tag_costs, blocked, no_stop. |
| `:reachable` | `fun(start: table, budget: number, rules?: table): {x: integer, z: integer, layer: integer, cost: number, parent: integer, stop: boolean}[]` | Every cell reachable within a movement budget (tactical move ranges). `parent` indexes the list (0 = start). |
| `:line_of_sight` | `fun(from: table, to: table, layer?: integer, blocking_tags?: string[]): boolean` | Whether terrain blocks the straight line between two points. |
| `:area` | `fun(centre: table, shape: 'diamond'/'square'/'cross'/'line'/'cone'/'ring', min: integer, max: integer, direction?: table): table[]` | Cells covered by a shape around a cell (attack ranges, areas of effect). |
| `:pick` | `fun(x: number, y: number): table?, table?` | Grid cell and point under a canvas position (mouse picking). |
| `:overlay` | `fun(name: string, cells: table[], options?: {color?: any, pulse?: number, order?: integer, border?: boolean, visible?: boolean})` | Highlight grid cells (move and attack ranges). |
| `:clear_overlay` | `fun(name?: string)` | Remove one overlay or all of them. |
| `:overlay_path` | `fun(name: string, cells: table[], color?: any)` | Draw a path arrow through cells. |
| `:cursor` | `fun(cell: table/nil, color?: any)` | Show the grid cursor on a cell; nil hides it. |
| `:burst` | `fun(position: table, settings: table, count?: integer)` | One-shot particle burst. |
